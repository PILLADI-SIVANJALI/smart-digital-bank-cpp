# Smart Digital Bank Management System

A C++ based banking application developed using Object-Oriented Programming and file handling. The system provides basic banking operations through a simple and user-friendly console interface.

## Features

- User Registration
- User Login
- Deposit Money
- Withdraw Money
- Balance Enquiry
- Money Transfer
- Transaction History
- File-Based Data Storage
- Input Validation

## Technologies Used

- C++
- Object-Oriented Programming
- File Handling
- Standard C++ Libraries

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Member Functions
- Data Abstraction

## Project Workflow

1. User registers an account.
2. User logs into the banking system.
3. User accesses the banking dashboard.
4. User can perform banking operations such as deposit, withdrawal, balance enquiry and transfer.
5. Transactions are recorded for future reference.

## Project Objective

The objective of this project is to develop a simple digital banking system that demonstrates the practical application of C++ Object-Oriented Programming, file handling, validation and transaction management.
